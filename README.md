# UNO Game – Java Project

A console-based version of the UNO card game built in Java as our first OOP project. We chose UNO because the rules are simple enough to understand but the logic behind it (turns, card effects, direction changes) gave us enough to work with when thinking about how to structure the classes. The game supports from 2 up to 4 players and each one can be either a human or a computer-controlled opponent. Wins are saved to a CSV file so the scoreboard is exported between sessions.

**Authors:** Miguel Fernández de la Cigoña París & Xurxo Lago Álvarez
